# Coco Explore

Guide gratuit en ligne pour voyager avec son chien en France (plages, restaurants, hébergements, balades, lacs, vétérinaires, toiletteurs, dogwash, garde, éducation canine, activités). Site statique Eleventy (11ty), 101 départements (96 métropolitains + 5 DOM), ~11 300 fiches FR et leurs versions EN partielles. Branche de travail et de production : `claude/github-connexion-otichf` (Netlify, projet `cocoexplore`).

**Ce fichier est la version courte (allégée le 13/11/2026).** Tout l'historique détaillé des chantiers, décisions passées, listes de fiches gardées/supprimées et pistes anciennes est dans `HISTORIQUE.md` (non chargé automatiquement) : y chercher avec `grep` avant de rouvrir un sujet (fiche déjà tranchée, établissement à ne pas recréer, doute déjà documenté).

## Conventions du projet (voir aussi contexte de session)

- **Signature des mails (12/11/2026, demande de l'utilisateur)** : toujours « Damien » puis « Coco Explore — cocoexplore.com », **jamais le nom de famille** de l'utilisateur (ni dans la signature ni dans le corps).
- **Tout ce qu'on ajoute doit être lié au chien** (rappel de l'utilisateur, 29/10/2026) : lieux et établissements qui accueillent les chiens (preuve officielle), services pour chiens (vétérinaires, toiletteurs, dogwash, garde, éducation), ou information utile au propriétaire de chien (règle d'interdiction d'un lieu très fréquenté, titre explicite). Jamais un lieu « généraliste » sans rapport avec le chien.
- **Toute nouvelle fiche est créée en mode SIRENE, rigueur maximale, sans exception** (règle de l'utilisateur, 29/10/2026) : chaque information lue sur une source officielle (site de l'établissement, mairie, arrêté, office de tourisme, gestionnaire), rien d'inventé, doutes visibles si les sources divergent, pas de doublon avec une fiche existante. Méthode : `scratchpad/brief-verif.md` + brief de création du chantier en cours.
- Fiches : `src/fiches/*.njk`, frontmatter YAML + `bodyHtml`.
- Jamais de photo Unsplash dupliquée entre fiches (vérification regex sur `photo-XXXX` avant chaque commit de contenu).
- Jamais le label `"Urgences"` avec un pattern 24h/24 sauf si réellement vérifié (déclenche un badge automatique `vetBadge`).
- `order` unique par fiche, nouvelles plages allouées par lot d'écriture.
- **Crédits Netlify : regrouper les mises en ligne.** Chaque `git push` sur `claude/github-connexion-otichf` déclenche un déploiement de production, qui consomme des crédits Netlify (le compte a été à court le 23/10/2026, et les déploiements se sont arrêtés). Donc : committer en local autant que nécessaire, mais **ne pousser qu'environ une fois par heure, ou à la fin d'un chantier** — jamais après chaque petit lot. Pour un commit qui ne change pas le site publié (fichiers `.md` à la racine : `CLAUDE.md`, `SEO-PRIORITES.md`, `ECHANGES-LIENS.md`…), ajouter **`[skip netlify]`** dans le message de commit : Netlify ne lance alors aucun déploiement. Attention, un push contenant à la fois un commit `[skip netlify]` et d'autres commits est déployé normalement (c'est le dernier commit poussé qui compte).
- **Crédits Netlify épuisés le 12/11/2026, rechargés par l'utilisateur le même jour** (cycle jusqu'au 27/11) ; mise en ligne de rattrapage le 12/11 (fiches minces lots 12-19, suppressions du lot 6). **Après recharge : une seule mise en ligne par jour au maximum.** Projets Netlify inutilisés `coco-explore` et `coco-explore-n3e4` supprimés par l'utilisateur le 12/11/2026 (suppression : Project configuration → Configuration → Danger zone) ; seul reste `cocoexplore` (ec8f1754…, cocoexplore.com).
- **Mémoire (07/11/2026)** : le build Eleventy dépasse la mémoire par défaut de Node (~2 Go, plantage « heap out of memory ») ; en local, lancer `NODE_OPTIONS=--max-old-space-size=4096 npx @11ty/eleventy` (sinon `_site` reste l'ancien et check-site passe à tort) ; sur Netlify, `NODE_OPTIONS` est fixé dans `netlify.toml` ([build.environment]).
- Build de vérification avant tout commit : `npx @11ty/eleventy && node scripts/check-site.mjs` (les deux doivent passer). Sur Netlify, `npm run build` (`scripts/build.mjs`) enchaîne les deux : **si l'un échoue, le déploiement échoue, la version précédente reste en ligne, et l'utilisateur reçoit une notification ntfy « Mise en ligne bloquee » avec le détail de l'erreur** (variable `NTFY_TOPIC`, scope builds + functions, build de production uniquement). Il bloque : plus de 20 pages en noindex, sitemap qui perd des fiches, « confiance X » dans `title`/`description`/`cardTeaser`, photo Unsplash (`heroImage`) partagée par deux fiches françaises, gabarit `{…}` non remplacé sur les pages catégorie. Ne jamais contourner ce contrôle : corriger la cause.
- **Contrôles avant chaque commit de contenu** : `node scratchpad/yamlcheck.mjs` (clés YAML en double), puis build `NODE_OPTIONS=--max-old-space-size=4096 npx @11ty/eleventy --quiet` + `node scripts/check-site.mjs` ; après un gros chantier aussi `python3 scratchpad/linkcheck.py`, `python3 scratchpad/htmllint.py`, `node scripts/check-mobile.mjs 40`, `python3 scratchpad/doublons.py`. `_site` n'est pas vidé par Eleventy : pour comparer les pages avant/après une suppression, comparer les URL des sitemaps (ou `rm -rf _site` avant le build).
- **Suppressions** : jamais sans décision de l'utilisateur. Toujours 301 dans `src/_redirects.njk` vers la page catégorie × département (vérifier qu'elle existe dans `_site`, sinon `/departement-<slug>`), attention aux fiches dont `permalinkPath` n'a pas le préfixe `fiche-`. Comparer les sitemaps avant/après : **garder une fiche dont la suppression ferait disparaître une page ville** (seuil 15 fiches, 10 pour les stations de `STATION_VILLES`). Les pages ville × catégorie et catégorie × département passées sous 5 fiches sont redirigées automatiquement (collections `cityCategoryRedirects`, `categoryDeptRedirects`).
- **Vie privée** : jamais de portable, nom ou adresse de domicile d'un particulier (pet-sitters, éducateurs à domicile, bénévoles de clubs) ; position au centre de la commune (`GPS-CENTRE`). Les numéros publiés par un établissement lui-même sont gardés. Jamais de numéro surtaxé (08 9x).
- **Titres** (ils pilotent le classement des pages ville, filtre `dogStatusIs`) : restaurant « Nom, Commune : restaurant chien accepté[, terrasse] » ; hébergement « <Nom avec type>, <Commune> : chien accepté[, supplément N €/nuit] » ; vétérinaire « Nom, Commune : horaires, téléphone[, urgences 24h/24] » (24h/24 seulement si `vetBadge` s'affiche) ; toiletteur « Toiletteur <commune> : <nom> » ; garde « Pension canine / Garde de chien / Pet-sitter <commune> : <nom> » ; dogwash « Dogwash <commune> : <enseigne>, lavage chien libre-service » ; lac « <Lac> (<commune>) avec chien : <règle> ». « chien accepté » seulement sur source officielle ; refus officiel → « chiens non acceptés » dans le titre (fiche gardée) ; sinon titre neutre. Supplément seulement net, avec unité.
- **Badge « Urgences 24h/24 »** (`vetBadge`) : seulement si le site de la clinique annonce un service assuré par elle-même (sur place ou astreinte). Garde partagée, renvoi vers une autre clinique, service d'appels externe la nuit ou urgences réservées à la clientèle → pas de badge, libellé « Urgences (selon l'établissement) ». Les mots « annoncé par », « revendiqué »… neutralisent le badge.
- **Plages et lacs** : champ `regleChien` obligatoire (`toute-annee` / `saisonnier` / `zones` / `interdit` / `incertain`).
- **Texte public** : chaque doute dit une fois, dans l'encadré « À vérifier… » ; carte « Sources » dans l'aside avec les sources réellement lues (« lues le JJ/MM/AAAA ») ; jamais de jargon de travail (« confiance », « round », « lors de cette recherche », « ancienne fiche », « je/nous »). **Ne jamais renommer une ligne infoItems « Confiance »** (masquée à l'affichage par `publicInfoItems`).
- **Fiches EN** (`src/en/fiches/*-en.njk`, `altLangUrl`) : à resynchroniser quand la FR change (mêmes faits).
- **Agents de recherche** : Parallel Search (`mcp__Parallel_Search__web_search` / `web_fetch`, à charger avec ToolSearch) contourne le blocage réseau des annuaires ; lots de ~10 fiches, ~3 agents Sonnet en parallèle au plus (limite de débit) ; outil Edit seulement sur les fiches, pas de build ni de git dans les agents ; post-traitement des lots par script (`scratchpad/*-post.sh NN` : lignes `GPS:`, `GPS-CENTRE:`, `GPS-POINT:` appliquées par `gps-from-report.py` / `gps-centre.py`, BAN avec contrôle de commune ; recalage à la seule rue refusé au-delà de 800 m). Briefs dans `scratchpad/brief-*.md` (`brief-consolider.md`, `brief-doutes.md`, `brief-verif.md`).
- **Ce qu'on ne crée pas / ne fait pas** (décisions de l'utilisateur) : pas de noindex de masse ni de retrait de pages pour Google ; pas de grosses vagues de nouvelles fiches tant que la chute Google n'est pas comprise ; pas de page « Coco y est allée » ; pas de FAQ de ville (texte identique) ; pas d'AdSense ; pas de badge gratuit « Référencé » ; pas de lien affilié sur les fiches lieux ni vers l'alimentation (respect de Bimo) ; Dogfy Diet écarté ; hôtels Perla Rossa (L'Île-Rousse) et Les Alcyons (Le Lavandou) à ne pas créer.

## Mécanique du site (repères)

- Pages ville : `computeCityPages` (`eleventy.config.js`), page dès 15 fiches (10 pour `STATION_VILLES`) ; blocs « L'essentiel » dans `src/_data/villesEssentiel.json` (villes) et `deptEssentiel.json` (101 départements) ; « En bref » calculés (`cityBrief`, `catBrief`) ; restaurants/hébergements à titre neutre ou refus dans un bloc replié.
- Seuils : pages ville × catégorie et catégorie × département dès 5 fiches (`CITY_CAT_MIN_FICHES`, `minFiches` de `categoryPages.js`).
- Programme partenaire : `partenaire: true` → badge doré et priorité d'affichage (sauf gardes 24h/24 vétérinaires d'abord) ; page `/devenir-partenaire` ; tarif cible 19-29 €/mois, 1er mois offert ; un seul badge, payant.
- Avis visiteurs : modération avant publication (`netlify/functions/avis.mjs`, `/admin-avis` protégé par `ADMIN_KEY`, jamais écrit), notification ntfy (`NTFY_TOPIC`). Espace pro : `/espace-pro` → `/api/pro` (ntfy).
- Données structurées des fiches : lieu (type selon la catégorie, téléphone/adresse nets via `ldContact`), fil d'Ariane, et bloc `WebPage` avec `dateModified` (date git de la fiche, au plus tôt le 31/10/2026).
- Guides `/guides` (`src/guides/*.njk`, `sources` + `updated` à tenir à jour, tarifs transport à revérifier au moins une fois par an ; tarif/sac Air France non publiés par la compagnie). Encadrés affiliés Maxi Zoo (Awin) seulement dans les guides Avion, Train, Ferry, Voiture (`rel="sponsored"`, mention « Liens affiliés »).
- Échanges de liens suivis dans `ECHANGES-LIENS.md` ; messages de demande de liens prêts dans `propositions/liens-entrants/messages.md` (envoyés par l'utilisateur, signature « Damien »).
