# Démarchage — badge « Référencé sur Coco Explore »

Fichier de travail non publié (racine du dépôt). Page publique : https://cocoexplore.com/badge-coco-explore (code du badge à copier, versions claire et sombre). Objectif : obtenir des liens vers le site depuis les sites des professionnels référencés et des offices de tourisme (autorité du domaine, indexation).

Conseils d'envoi :
- Commencer par les établissements qui ont un vrai site (hébergements, restaurants, toiletteurs, dogwash, pensions) et une fiche bien complète.
- Toujours mettre le lien exact de LEUR fiche : c'est ce qui donne envie.
- Petits lots (10-20 par semaine), personnalisés ; pas d'envoi de masse.
- Suivre les retours dans `ECHANGES-LIENS.md` (colonne « lien reçu »).

## 1. Email aux professionnels référencés

```
Objet : Votre établissement est référencé sur Coco Explore (guide voyage avec chien)

Bonjour,

Je gère Coco Explore, un guide gratuit qui aide les propriétaires de chiens à
trouver des adresses qui les accueillent partout en France. [Nom de
l'établissement] y est référencé, avec vos conditions d'accueil des chiens :
[lien vers la fiche]

Si vous le souhaitez, vous pouvez afficher gratuitement sur votre site un petit
badge « Référencé sur Coco Explore », qui renvoie vers votre fiche. Il rassure
les clients qui voyagent avec leur chien. Le code est prêt à copier ici :
https://cocoexplore.com/badge-coco-explore

Et si une information de votre fiche n'est plus à jour (horaires, tarifs,
conditions pour les chiens), répondez simplement à ce message : je la corrige.

Belle journée,
[Prénom Nom]
Coco Explore — cocoexplore.com
```

## 2. Message court (formulaire de contact, Facebook, Instagram)


## 3. Email aux offices de tourisme

```
Objet : Ressource pour vos visiteurs avec chien — [nom de la commune / du territoire]

Bonjour,

Je gère Coco Explore, un guide gratuit et indépendant pour voyager avec son
chien en France. Nous avons rassemblé, pour [territoire], les adresses qui
accueillent les chiens, avec les règles vérifiées :
- plages : [lien /plage-chien-<département> si elle existe]
- balades : [lien /balade-chien-<département>]
- hébergements et restaurants : [liens]
- [ville] avec son chien : [lien /<ville>-avec-son-chien si elle existe]

Beaucoup de vos visiteurs viennent avec leur chien : si ces pages peuvent leur
être utiles, n'hésitez pas à les mentionner sur votre page « vacances avec son
animal » ou dans vos réponses. Et si vous voyez une information à corriger
(arrêté plage, accès), je la mets à jour avec plaisir.

Belle journée,
[Prénom Nom]
Coco Explore — cocoexplore.com
```
